# DataVexa Studio — Upgraded Flask Website\n\nThis package upgrades the existing site with conversion-focused contact links, service pricing, SEO routes, CSRF protection, rate limits on login/contact submissions, security headers, and a lead CRM in the admin dashboard. Existing SQLite data is preserved by additive migrations.\n\n## Upgrade safely (Windows PowerShell)\n1. Stop the running Flask server with `Ctrl+C`.\n2. Back up your existing `instance\datavexa.db` and `static\uploads` folder. For example, from the project folder run: `Copy-Item .\\instance\\datavexa.db .\\instance\\datavexa-backup.db` (if the database exists).\n3. Extract this upgraded ZIP to a NEW folder first, not over the current folder. This package intentionally does not include your live database.\n4. Copy your original `instance\datavexa.db` into the upgraded folder's `instance` folder, and copy the contents of your old `static\uploads` into the upgraded `static\uploads` folder. If you already use this extracted package as the original, skip the copy and keep the original DB in place.\n5. In PowerShell, open the upgraded folder containing `app.py` and run: `py -m pip install -r requirements.txt`.\n6. Start with `py app.py`. The app automatically adds CRM columns to existing `messages` tables without deleting records.\n7. Log into `/admin`; update the status, follow-up date and internal notes for each inquiry. Use **Export CSV** to download the leads.\n\n## First-time local setup\n```powershell\npy -m venv .venv\n.\\.venv\\Scripts\\python.exe -m pip install -r requirements.txt\n.\\.venv\\Scripts\\python.exe app.py --create-admin tamilmani YOUR_STRONG_PASSWORD\n.\\.venv\\Scripts\\python.exe app.py\n```\nThen open `http://127.0.0.1:5000`. Admin: `http://127.0.0.1:5000/admin`.\n\nIf the admin account already exists, do not create it again with the same username. Use your existing login.\n\n## Features\n- Responsive homepage, services, pricing, project library, showcase and case-study detail pages.\n- Contact page with email, WhatsApp, Instagram, LinkedIn and GitHub links.\n- Project CMS: add/edit/delete, feature, publish/unpublish and image upload.\n- Client lead CRM: stages New / Contacted / Qualified / Won / Lost, follow-up date, private notes and CSV export.\n- CSRF protection for forms, login/contact rate limits, basic security headers, 8 MB upload cap.\n- `/robots.txt`, `/sitemap.xml`, and `/health` routes.\n\n## Contact details included\n- Email: datanovi.studio@gmail.com\n- WhatsApp: +91 9751059227\n- Instagram: https://www.instagram.com/datavexa.studio/\n- LinkedIn: https://www.linkedin.com/in/sbtamil010/\n- GitHub: https://github.com/sbtamil010-cloud\n\n## Before public deployment\nThis remains a starter project and is not hosted publicly by this ZIP. Set `SECRET_KEY` and `PUBLIC_BASE_URL` in your hosting environment; set `COOKIE_SECURE=1` when HTTPS is enabled; use a production WSGI server; keep debug off; add monitoring/backups and test restore; and verify HTTPS, upload handling and admin access. The rate limiter currently uses in-memory storage, which resets when the app restarts and is not shared across multiple workers; use Redis or a provider-backed limiter for a scaled deployment. Contact submissions are stored in the database and do not automatically email you.\n\n## Important database note\nThe startup migration only adds missing columns to `messages`. It does not intentionally drop tables or delete projects/messages/admins. Always keep a backup before upgrades.\n
